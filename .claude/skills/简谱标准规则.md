# 简谱标准规则

## 一、简谱基本记谱法

### 1.1 音符
| 数字 | 唱名 |
|------|------|
| 1 | do |
| 2 | re |
| 3 | mi |
| 4 | fa |
| 5 | sol |
| 6 | la |
| 7 | si |

### 1.2 音高标记
- **高音**: 数字上方一个点 `˙1`
- **倍高音**: 数字上方两个点 `¨1`
- **低音**: 数字下方一个点 `.1`
- **倍低音**: 数字下方两个点 `..1`

### 1.3 时值
| 时值 | 记法 |
|------|------|
| 全音符 | `1---` |
| 二分音符 | `1-` |
| 四分音符 | `1` |
| 八分音符 | 数字下方一横线 |
| 十六分音符 | 数字下方两横线 |

### 1.4 休止符
- 四分休止: `0`
- 八分休止: `0̅`

### 1.5 附点
- 附点音符：数字右侧加点 `1·`
- 附点休止：`0·`

### 1.6 小节线
- 单纵线 `|` 分隔小节
- 双纵线 `||` 段落结束
- 终止线 `‖` 乐曲结束

## 二、调号与拍号

- 调号格式：`1=C`、`1=G`
- 拍号格式：`2/4`、`3/4`、`4/4`、`6/8`
- 速度：`♩=120` 或中文 `行板`、`快板`

## 三、表情记号

| 记号 | 含义 |
|------|------|
| p | 弱 |
| f | 强 |
| mf | 中强 |
| cresc. | 渐强 |
| dim. | 渐弱 |
| tr | 颤音 |
