## 二、错误分类指南

### 数据库错误
| 症状 | 排查方向 |
|------|----------|
| 连接超时 | 检查 MySQL 服务和连接配置 |
| SQL 语法错误 | 检查 SQL 语句和参数绑定 |
| 外键约束失败 | 检查外键关系和级联策略 |
| 查询结果为空 | 检查 SQL 条件和表名 |

### 后端错误
| 状态码 | 排查方向 |
|--------|----------|
| 400 | 检查请求参数格式 |
| 404 | 检查路由和数据存在性 |
| 500 | 查看服务器日志堆栈 |
| CORS | 检查 cors 中间件配置 |

### 前端错误
| 症状 | 排查方向 |
|------|----------|
| 组件不渲染 | 检查 props 和初始状态 |
| API 调用失败 | 检查请求路径和网络 |
| 状态更新异常 | 检查不可变性更新 |
| 路由不生效 | 检查路由配置和路径 |

## 三、排查流程

```
发现错误 → 复现确认
  ├── 前端 → 浏览器控制台 → Network/Console
  ├── 后端 → 终端日志 → 错误堆栈
  └── 数据库 → 手动执行 SQL → 检查数据
       → 定位根因 → 记录 → 修复 → 验证
```
