# 输出解析为中文规范

## 一、核心原则

所有用户可见的文字**必须使用中文**（简体）。

## 二、UI 文字中文映射

| 英文 | 中文 |
|------|------|
| Home | 首页 |
| Scores | 乐谱库 |
| Score | 乐谱 |
| Section | 乐段 |
| Review | 审阅 |
| Comments | 评论 |
| Cancel | 取消 |
| Save | 保存 |
| Delete | 删除 |
| Edit | 编辑 |
| Create / Add | 新增 |
| Loading | 加载中… |
| No Data | 暂无数据 |
| Composer | 作曲者 |
| Tempo | 速度 |
| Key Signature | 调号 |
| Time Signature | 拍号 |
| Open (status) | 待处理 |
| Resolved | 已解决 |
| Approved | 已通过 |
| Created Successfully | 创建成功 |
| Updated Successfully | 更新成功 |
| Deleted Successfully | 删除成功 |
| Network Error | 网络错误，请稍后重试 |

## 三、日期时间格式

- 完整日期：`2026年6月9日`
- 相对时间：`刚刚`、`5分钟前`、`1小时前`、`昨天`、`3天前`
- 超过 7 天显示完整日期

## 四、音乐术语中译

| 原文 | 中文 |
|------|------|
| Allegro | 快板 |
| Andante | 行板 |
| Adagio | 柔板 |
| Forte (f) | 强 |
| Piano (p) | 弱 |
| Crescendo | 渐强 |
| Diminuendo | 渐弱 |
| Da Capo | 从头反复 |
| Fine | 结束 |

## 五、实现要求

1. 所有 JSX/TSX 展示字符串必须用中文
2. 错误消息必须用中文返回
3. 变量名、函数名等代码内部标识符保留英文
